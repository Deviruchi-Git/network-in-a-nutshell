เมื่อเริ่มจับ network 1 ในชื่อแรกๆ ที่มักจะได้ยินเสมอคือ spanning tree เจ้าต้นใหม่ผู้แผ่กิ่งก้านสาขานี่แหละ ที่ในทางเนื้อหาฟังดูเหมือนจะง่าย แต่ถ้าพอเจอเวลามันมีปัญหา คือ 1 ใน ticket ที่น่าปวดหัวสุดๆ ของเหล่า network engineer 

![](/images/scr-20260815-qcfg.png)

> Spanning-tree คือ graph รูปแบบหนึ่งซึ่งได้จากกระบวนการ algorithm ในการทำ loop prevention

ทุกครั้งที่ได้ยินเรื่องนี้ network engineer ต่างคิดว่ามันไม่น่าจะซับซ้อน เพราะในทุกครั้งแทบไม่มีการ config ใดใดเพื่อให้มันทำงานได้ เพราะมันทำงานโดยอัติโนมัติอยู่แล้ว  แต่ครั้งเมื่อเจอปัญหาการตรวจสอบ spanning-tree ก็มักจะเป็นหนึ่งในเครื่องมือที่ถูกนำมาใช้และหลายคนก็ยังมองข้ามกระบวนการสำคัญต่างๆ ของมันไป
